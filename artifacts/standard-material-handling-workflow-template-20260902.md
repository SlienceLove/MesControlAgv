# 料盘四段标准流程模板

日期：2026-09-02（Asia/Shanghai）

## 模板顺序

模板已加入 WPF 流程管理页，入口为“料盘四段标准模板”。生成的线性流程固定为：

1. `从原点开始`：前置条件为 AGV 已位于原点，现场区域安全。
2. AGV 前往站点1，执行 `取料盘.pro`。
3. AGV 前往站点2，执行 `放料盘.pro`。
4. AGV 返回站点1，执行 `回收料盘.pro`。
5. AGV 返回原点，流程结束。

每个移动和机械臂程序节点只连接到下一个成功节点；程序节点不会自动重试。

## 站点解析

WPF 优先读取当前 Profile 中名称为“站点1”和“站点2”的站点；本次现场已确认实际映射如下：

- 原点：`Charge` 类型，当前为 `LM1`；
- 站点1：`LM7`；
- 站点2：`LM2`。

创建后，界面消息会显示实际解析出的站点 ID。本次确认结果与模板预填一致。

## 程序和现场门禁

模板预填三个显示程序名，但 AUBO 适配器会在授权和执行前去除 `.pro` 后缀并按当前只读目录/允许列表校验。现场执行前必须：

- 通过有线控制网完成新的 AGV 和 AUBO 只读预检；
- 确认三个实际程序在当前控制器目录中，且与模板逐字匹配；
- 确认 AUBO 为 `Automatic / Normal / Stopped`，AGV 位置、定位、急停、故障和地图证据均新鲜；
- AGV 定位置信度必须达到当前已批准的现场软件门槛 `0.90`；本次门槛调整不替代定位质量确认；
- 为每一段 AGV 移动和每个机械臂程序取得独立的现场授权；
- 在 WPF 中完成保存、校验和发布。

本次只创建模板并做离线测试，没有启动 PhysicalAcceptance，没有开启物理 worker，也没有调用 AGV/AUBO 写接口。网络恢复本身不等于执行授权。
