# ShineLab 标准版中文说明书分析（2026-08-28）

## 文件

- 文件：ShineLab标准版中文说明书V3.0.pdf
- 页数：62
- SHA-256：1D3292DDA0F04D814FA9B358F899BA8A5FF3D445816CC009B09569A08D287F79
- 来源：控制电脑共享目录 MES-RPA-Inbox
- PDF 元数据创建时间为 2025-10-20；当前现场 ShineLab 为更新后的构建，
  因此菜单名称/列显示可能略有差异，以下路径需以现场实际界面为准。

## 核心结论

现场截图中的 ShineDataAcquisition - D160+-test111 是数据采集运行窗口。
样品位、进样体积和自动进样器模式不在这个窗口顶部的运行/暂停/恢复/终止
工具栏中，而分布在三个配置层级：

1. 仪器配置：把 SHA-18 的通道加入当前仪器并连接 COM；
2. 色谱方法：勾选进样器信号并设置自动进样器相关参数；
3. 序列方法的样品编辑表：填写进样盘编号、进样体积等每行样品参数。

## 说明书给出的菜单路径

### 1. 添加并连接 SHA-18 通道

PDF 第 19 页（印刷页 18，章节 3.4“配置仪器”）：

    仪器 → 仪器管理 → 配置

右侧选择已配置设备，点击左箭头加入当前仪器。说明书示例明确提到：

- 双通道自动进样器 SHA-18 的通道 SHA-18A；
- 配置后双击设备；
- 手动选择端口；
- 点击“自动连接”；
- 点击“确定”保存仪器配置。

现场截图已经证明：当前仪器 D160+ 左侧树中已有 SHA-18iA-SHA-18，
右侧 SHA-18iA 已勾选，连接设置为 COM3。因此“没有添加 SHA-18”不是当前
主要问题。

截图中的“启用样品盘检测”当前未勾选。说明书没有要求必须勾选该项；它更像
缺瓶/托盘存在性检查开关。当前先保持原值，不要为了抓包临时修改。

截图底部还显示“修改仪器，已添加方法将被清空，需要重新添加方法”等警告。
因此当前阶段只查看配置，不要为了寻找进样字段而点击“确定”保存或重新组织
仪器组件；已有方法/序列应先备份。

### 2. 自动进样器控制/维护

PDF 第 23 页（印刷页 22，章节 4.5.1“仪器控制”）：

    仪器 → 仪器控制 → 仪器控制

说明书对自动进样器的标准控制描述为“初始化”和“洗针”；对 SHA-16
另列出初始化-洗针、复位、托盘复位、托盘弹出和温度值。说明书没有给出
SHA-18 的独立“抓针、移动到样品瓶、终止运行”按钮路径。

因此，标准 ShineLab 看不到低层抓针/托盘按钮是符合手册的；这些低层动作
更可能属于专用校准工具，而不是标准采集窗口。

### 3. 色谱方法中的进样器设置

PDF 第 24 页（印刷页 23，章节 4.6）：

    仪器 → 色谱方法管理

创建或编辑色谱方法时，在“采集信号”中选择“进样器信号”。手册说明：
配置自动进样器后，建立色谱方法时需要设定自动进样器参数。

如果没有勾选“进样器信号”，方法可能仍能运行 D160+ 采集，但不会按
自动进样器触发谱图采集。

### 4. 样品位和进样体积

PDF 第 27–28 页（印刷页 26–27，章节 4.7.1“创建序列方法”）：

    分析控制 → 样品编辑 → 创建 → 新建序列方法

或：

    分析控制 → 样品编辑 → 创建 → 使用现有序列方法

样品任务编辑表中的关键字段包括：

- “选择”：必须勾选，未勾选的行运行时会跳过；
- “进样体积[μL]”：设定样品进样体积，不能大于定量环体积；
- “进样盘编号”：选择样品进样瓶位置；
- “色谱方法”：选择已经配置自动进样器参数的色谱方法；
- “循环次数”：同一样品重复进样次数；
- “样品类型/样品等级/处理方法/清除校正”等业务字段。

当前现场导出的 13 列 CSV 和截图也确实没有显示“进样盘编号”。但离线检查
当前 `ShCDSUI.dll` 发现样品表仍保留 `IC_SamNo` 列标识、`ShColumnDlg`
对话框以及 `setcolumn`/`CreateColumnRClickMenus` 入口；这强烈提示该列可能
被“设置列”选择器隐藏，而不是数据库字段不存在。建议先在样品表的**列标题**
上右键，查找“设置列/选择列”，再搜索“进样盘编号/进样位置”。不要右键样品数据
单元格，也不要用 CSV 直接增加新列（当前导入器会拒绝非 13 列表头）。

PDF 第 31 页（印刷页 30，章节 4.11）说明，编辑完序列样品后通过
“分析控制 → 操作 → 运行”开始进样采集分析。

## 运行控制按钮的边界

同一页说明：

- “暂停”：完成当前进样谱图后暂停；
- “恢复”：暂停后继续下一针谱图；
- “终止”：当前谱图采集立即停止。

这些描述针对采集序列/谱图，不等同于 SHA-18i 机械动作的硬件急停。

## 结合本轮现场抓包的判断

现场按钮操作发生在 D160+-test111 窗口。抓包中 COM3/SHA-18i 只有周期
状态读取，没有动作写帧；COM4/D160+ 才出现运行路径写帧。因此下一轮
不能继续在 D160+-test111 上重复运行/暂停/恢复/终止来验证进样器。

## 现场下一步（先查看，不修改）

在确认 D160+ 已回到安全等待状态后，按以下顺序截图核对：

1. 仪器 → 仪器管理 → 配置：确认 SHA-18iA、COM3、自动连接状态；
2. 仪器 → 色谱方法管理：打开 D160+-test111 所使用的色谱方法，确认
   “采集信号”是否勾选“进样器信号”，并查看是否出现进样器参数页；
3. 分析控制 → 样品编辑：确认表格是否有“进样盘编号”和“进样体积[μL]”，
   当前行“选择”是否勾选；
4. 只有确认以上三项后，才在空载/测试授权下做一次被动抓包进样。

如果样品编辑表没有“进样盘编号/进样体积”，优先检查当前打开的是不是
序列方法编辑窗口，而不是已经导入的 D160+ 任务显示表。

说明书没有单独命名为“进样模式”的固定主窗口。当前 `ShDeviceFamilyUI.dll`
的 AS18 方法资源包含“进样模式、进样体积、定量环体积、清洗模式、清洗次数、
等待时间、前/后增量、管路体积、注射器体积、针高度、缺少样品瓶时、触发信号”等
控件；它们应在色谱方法编辑时选中 AS/SHA-18A 子设备页查看，而不是在当前
D160+ 顶部运行工具栏查找。

## 边界

本说明书没有提供 SHA-18i 的原始 Modbus 帧、停止寄存器或清洗寄存器。
在取得真实动作抓包前，不从手册文字推导写帧，也不把“终止”按钮当作
硬件停止证明。
