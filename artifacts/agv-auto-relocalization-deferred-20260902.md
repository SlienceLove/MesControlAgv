# AGV 自动重定位功能延期记录

日期：2026-09-02（Asia/Shanghai）

现场决定先继续既有料盘标准流程，暂不实现“置信度低于 `0.90` 自动重定位”。当前系统继续保持：

- 低于门槛时只读预检失败并阻止派发；
- 不在刷新、预检或普通派发路径中自动发送重定位写命令；
- 不自动调用厂家 API `2002`、`2003` 或 `2004`。

延期原因：现有资料只确认 API 编号和 `2002` 的示例 `x/y/angle` 载荷，尚未确认现场坐标来源、单位、坐标系、响应完成语义及 `2003` 人工确认流程。直接使用当前上报位姿进行自动重定位可能写入错误位置。

后续如重新评估，应先完成厂家协议确认，再采用独立、默认关闭、标准模式专用、单次请求、无自动重试并保留人工确认的实现。
