# MES Control AGV

面向实验室自动化场景的轻量中控 MES 项目，用于编排并追踪 AGV 在固定站点之间的物料搬运任务。

项目当前处于 MVP 方案验证阶段：先通过 AGV 模拟器验证任务闭环、异常恢复和操作追溯，再对接真实 AGV。

## MVP 目标

- 控制单台 AGV 在 7 个固定站点之间执行搬运；
- 验证“样品位 → 液体前处理工作站”的完整搬运闭环；
- 支持操作员确认取货和放货；
- 支持任务派发、状态追踪、失败重试、取消和服务重启恢复；
- 确保同一任务不会重复派发，并保存完整事件日志；
- 后续仅替换 AGV Adapter 的设备客户端，即可从模拟器切换到真实 AGV。

## 架构

```text
Web 前端
   │
   ▼
中控 MES 服务
   │ 任务状态机、人工确认、恢复决策、事件日志
   ▼
AGV Adapter
   │ 站点映射、任务幂等、设备协议与状态查询
   ├── AGV 模拟器（MVP）
   └── 真实 AGV（后续）
```

AGV Adapter 将中控业务任务与具体厂商协议隔离：中控只处理搬运流程和任务状态，Adapter 负责站点映射、控制权、幂等、超时后的真实状态确认，以及后续 TCP API 或 Modbus TCP 对接。

## 固定站点

| 编号 | 站点 | 机器站点 ID |
|---:|---|---|
| 0 | 充电桩 | `CHARGE_01` |
| 1 | 耗材位 | `PICK_01` |
| 2 | 样品位 | `SAMPLE_01` |
| 3 | 开盖分液工作站 | `ST_OPEN_01` |
| 4 | 液体前处理工作站 | `ST_PREP_01` |
| 5 | 自动进样器 | `ST_INJECT_01` |
| 6 | 样品回收位 | `DROP_01` |

## 任务流程

```text
创建任务
  → 前往取货站
  → 人工确认已取货
  → 前往放货站
  → 人工确认已放货
  → 完成
```

网络超时不会直接重发任务。系统会先按唯一 `task_id` 查询 AGV 的真实状态，再决定恢复、重试或标记异常。
