## 网络拓扑方案

### 方案 1：使用交换机（推荐，生产环境）

```
┌─────────────┐
│  中控 PC    │
│192.168.1.10 │
└──────┬──────┘
       │ 网线
       ▼
┌─────────────┐
│  交换机     │
│  (5-8口)    │
└──┬───┬───┬──┘
   │   │   │
   │   │   └─────────┐
   │   │             │
   ▼   ▼             ▼
┌──────┐  ┌────────┐  ┌──────────┐
│ AGV  │  │机械臂  │  │ 视觉系统 │
│.100  │  │.101    │  │ .102     │
└──────┘  └────────┘  └──────────┘
(WiFi)     (跟随AGV)   (跟随AGV)
```

**所需设备**：
- 1 台千兆交换机（5口即可，推荐 8 口备用）
- 3-4 根网线
- 如果 AGV 移动，需配置 WiFi AP

**优势**：
- ✅ 所有设备在同一网络
- ✅ 便于调试和监控
- ✅ 符合生产环境要求
- ✅ 可扩展（后续增加设备）

**预算**: ~200-500 元（普通交换机）

       ▼

       │              │

   ┌───────┐      ┌──────┐

**需要确认**：

### 方案 4：使用便携路由器（快速方案）

如果没有交换机，可以用一个**便携路由器**：

```
┌─────────────┐
│  中控 PC    │  WiFi 或网线连接
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 便携路由器  │ (有 4 个 LAN 口)
│192.168.1.1  │
└──┬───┬───┬──┘
   │   │   │
   ▼   ▼   ▼
  AGV 机械臂 视觉
```

**优势**：
- ✅ 便宜（50-100 元）
- ✅ 便携，方便现场调试
- ✅ 自带 DHCP，方便配置
- ⚠️ 性能可能不如交换机

**推荐型号**：
- TP-Link TL-WR840N
- 小米路由器 4A
- 华为路由器 WS5200

## 网络配置步骤

### 步骤 1: 配置中控 PC 静态 IP

**Windows 配置**：

1. 打开 `控制面板` → `网络和共享中心` → `更改适配器设置`
2. 右键你要用的网卡 → `属性`
3. 双击 `Internet 协议版本 4 (TCP/IPv4)`
4. 选择 `使用下面的 IP 地址`：

```
IP 地址:     192.168.1.10
子网掩码:    255.255.255.0
默认网关:    192.168.1.1 (如果有路由器)
首选 DNS:    8.8.8.8 (可选)
```

5. 点击 `确定`

**验证配置**：

```powershell
# 打开 PowerShell 或 CMD
ipconfig

# 应该看到：
# 以太网适配器 以太网:
#    IPv4 地址 . . . . . . . . . . . . : 192.168.1.10
#    子网掩码  . . . . . . . . . . . . : 255.255.255.0
```

### 步骤 2: 物理连接设备

#### 使用交换机：
1. 将中控 PC 网线插入交换机任意 LAN 口
2. AGV、机械臂、视觉系统都插入交换机
3. 交换机通电

#### 使用路由器：
1. 将中控 PC 连接到路由器（WiFi 或网线）
2. AGV、机械臂、视觉插入路由器 LAN 口

### 步骤 3: 验证网络连通性

```powershell
# 1. 检查本机 IP
ipconfig

# 2. 测试到 AGV 的连接
ping 192.168.1.100 -n 4

# 3. 测试到机械臂的连接
ping 192.168.1.101 -n 4

# 4. 测试到视觉系统的连接
ping 192.168.1.102 -n 4

# 5. 扫描网络中的设备（查看哪些 IP 在线）
# Windows 11:
arp -a

# 或使用 nmap（需要安装）
nmap -sn 192.168.1.0/24
```

**预期结果**：
```
正在 Ping 192.168.1.101 具有 32 字节的数据:
来自 192.168.1.101 的回复: 字节=32 时间<1ms TTL=64
来自 192.168.1.101 的回复: 字节=32 时间<1ms TTL=64
来自 192.168.1.101 的回复: 字节=32 时间<1ms TTL=64
来自 192.168.1.101 的回复: 字节=32 时间<1ms TTL=64

192.168.1.101 的 Ping 统计信息:
    数据包: 已发送 = 4，已接收 = 4，丢失 = 0 (0% 丢失)
```

### 步骤 4: 测试端口连接

```powershell
# 测试机械臂端口（假设 8080）
Test-NetConnection -ComputerName 192.168.1.101 -Port 8080

# 测试视觉系统端口（假设 8081）
Test-NetConnection -ComputerName 192.168.1.102 -Port 8081

# 或使用 telnet（需要先启用）
telnet 192.168.1.101 8080
```

**预期结果**：
```
ComputerName     : 192.168.1.101
RemoteAddress    : 192.168.1.101
RemotePort       : 8080
InterfaceAlias   : 以太网
SourceAddress    : 192.168.1.10
TcpTestSucceeded : True  ← 表示端口开放
```
