# 真实坐标标定预览部署

本步骤接续用户已确认的位姿设计与“继续下一步”。复用独立工作区，不改正式客户端、运行服务或调度器。

独立窗口仅实例化 `DigitalTwinView`，不执行 WPF App 的启动流程。状态经只允许 GET、禁止重定向的 HTTP 客户端访问现有 MES `127.0.0.1:15445`；位置由上一步已验证的 TcpAgvClient 以 read-only-preflight 模式读取 `192.168.1.2:19204`，不启动 Adapter 宿主、Push 或调度器。窗口明确标出两种来源。这是标定预览的临时接法，正式中控仍走 Adapter→MES→WPF。

不写入猜测标定。现有标定功能仍要求用户确认三维对应点、底盘参考点和朝向后才能保存。关闭窗口取消页面采样并释放 TCP／HTTP 资源。进程级互斥锁避免重复预览采集。

启动命令：`CalibrationPreview.exe --live-readonly <evidence-directory>`。默认无参数不会连接设备。部署为独立目录；启动证据记录于 `startup.json`，实际界面截图为 `live-preview.png`。

当前需要现场确认的第一项：在三维里指出 LM1（充电原点）的底盘中心地面位置。导航坐标已经从原地图读取，无需用户输入；不得把 CAD 中复合机器人的初始放置位置自行认作 LM1。然后对应 LM2 和非共线的 LM6（或其他已知点），检查残差及车头方向。
