# AGV / 机械臂 / 视觉 / 总控联调交接摘要

更新时间：2026-08-28

## 范围

新会话只处理总控电脑、单台 AGV、机械臂、视觉和实验流程编排。D160+ / SHA-18i 双串口代理由另一个会话负责；本会话不连接仪器 COM、不读取仪器、不发送仪器写帧。

## 最新优先级覆盖（2026-08-30）

当前现场第一优先级改为**先联通机械臂**。在批准的控制电脑上，先完成 AUBO JSON-RPC
网络链路、设备身份、运行/安全模式、Lua 工程和白名单变量的只读确认；本阶段不发送变量写入、
程序启动、控制权申请、夹爪动作或运动命令。机械臂只读证据未通过前，不进入 AGV 移动、I/O
触发或机械臂空载握手。

四项现场变量契约（命令变量键、整数到动作映射、`ack`/`result` 键名与结果码、完成回复方式）
必须由现场/厂家确认，不能从历史抓包或代码默认值推导。离子色谱与 SHA-18i/自动进样器现场
验证降为机械臂只读联通之后的 P1；O24 及后续离线快照工作暂停。

|---|---|---|
| 总控电脑 | `192.168.1.11/24` | 本机联调时使用的有线地址 |
| AGV 控制器 | `192.168.1.2` | 当前现场实际确认的 AGV |

AGV 现有现场接口：`19204` 状态、`19206` 命令、`19207` 控制权、`19210` 其他/IO、`19301` Push。现场验收阶段默认关闭 Push。

## 下一次现场执行顺序

### 1. 接线和安全

- 总控电脑接交换机；
- AGV 上电；
- 作业区隔离；
- 急停、人工接管和停止路径有人负责；
- 本轮只纳入 AGV-01；
- 机械臂、视觉和仪器不做动作。

### 2. 改址和网络检查

管理员 PowerShell 执行改址脚本，将本机有线地址改为 `192.168.1.11/24`。

随后执行：

```powershell
ping 192.168.1.2
Test-NetConnection 192.168.1.2 -Port 19204
Test-NetConnection 192.168.1.2 -Port 19207
```

只读阶段不要连接或写入 `19206`。

### 3. 新鲜只读预检

使用独立 `read-only-preflight` Adapter 和隔离数据库，不使用模拟 Adapter、开发数据库或历史状态。

必须确认：AGV 在线、当前站点可读、无活动任务、控制权为 `none`、急停/阻塞/Fatal/Error 正常、定位查询 `1021` 成功、地图名称/版本/MD5/站点/有向边与控制器权威快照一致、定位置信度达标。

任一必要证据缺失，保持 `NO-GO`，不得移动。

### 4. 单段低速移动

只有在预检通过、书面授权、现场安全监护到位后，才启动独立标准模式 Adapter 并申请控制权。

第一段建议：

```text
LM1 → LM2
```

每段使用新的 permit/task ID，限速 `0.3 m/s`，单次派发，不自动重试；必须轮询到站并确认后才能执行下一段。

### 5. 完整往返

按控制器当前有向图逐段执行，不假设存在反向边。候选路线：

```text
LM1 → LM2
LM2 → LM3
LM3 → LM1
```

每段都要单独记录授权、控制权、预检、派发、移动、到站和释放。

### 6. 异常和收尾

超时、障碍、人工接管、急停或未确认结果进入 `unknown/manual_intervention_required`，不得自动重试或复用任务 ID。正常结束必须确认任务完成、车辆静止、控制权释放、Adapter 停止并完成审计归档。

## 安全边界

- 不恢复双串口仪器读取；
- 不在只读预检中获取 AGV 控制权；
- 不自动发送移动、取消或恢复命令；
- 不复用历史 permit/task ID；
- 机械臂和视觉接入前，先完成单 AGV 现场验收。
