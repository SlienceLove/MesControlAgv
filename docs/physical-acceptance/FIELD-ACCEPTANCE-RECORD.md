### 12.2 离线根因

- 控制器对不存在的任务 ID 会返回**非空**的 `1110.task_status_list` 条目，
  其 `status=404`。
- `TcpAgvClient` 原先把任何非空列表当作幂等命中，直接返回 `unknown` 并在写入
  `3066` 之前退出。临时 SQLite 中 `dispatching -> unknown` 且无设备错误的序列与该
  路径一致。
- 旧 Adapter 日志没有保留原始 mutation 请求/响应数据。因此**不得**声称本次会话
  观察到任何特定的 `3066 ret_code`，也不得断言控制器接受或拒绝了该写入。
- 厂家 PDF 另行确认 `3066` 使用 `move_task_list` 外层封装，每项需要 `task_id`、
  `source_id`、`id`，且单项 `max_speed` 为可选、单位 `m/s`。因此
  `max_speed=0.3` 不是本次命令前退出的原因。
