# 单 AGV 总控联调计划（2026-08-28）

## 范围

本轮只验证：总控电脑 → 单台 AGV 控制器 → 位置/任务状态回传。

本轮不连接或不执行：机械臂、视觉、D160+、SHA-18i、ShineLab 仪器流程。

目标是跑通一台 AGV 的完整受监督链路：

```text
网络接入 → 只读预检 → 获取控制权 → 单段移动 → 到站确认
→ 下一段移动 → 返回/结束 → 释放控制权 → 审计归档
```

## 现场网络

厂商表确认：

| 设备 | 地址/端口 | 本轮用途 |
|---|---|---|
| 总控电脑 | `192.168.1.11/24` | 唯一控制客户端 |
| AGV 控制器 | `192.168.1.2` | 单台 AGV |

总控电脑使用有线网卡连接交换机，配置 `192.168.1.11/24`，不在该网卡配置默认网关；WLAN 保持关闭或使用不同网段。不要把机械臂、视觉的地址配置到总控电脑上。

总控电脑管理员 PowerShell 的网络验证：

```powershell

```

在只读预检阶段不连接或写入 `19206`，除非现场已进入单段移动授权阶段。

## 阶段 1：只读预检（必须每次新会话执行）

使用独立的 `read-only-preflight` Adapter，不使用正在运行的模拟 Adapter，不复用历史数据库。

必须确认：

- 车辆在线；
- 当前站点可读；
- 当前无活动任务；
- 控制权持有者为 `none`；
- 急停、阻塞、Fatal、Error 均正常；
- 定位查询 `1021` 成功；
- 控制器地图名称、版本、MD5、站点和有向边与批准 Profile 一致；
- 定位置信度达到当前阈值；
- `DispatchPermitted=false` 仅因尚未进入授权标准模式，而不是其他安全门禁失败；
- 只读 Adapter 完成后已停止并释放端口。

任何地图、定位、车辆状态或控制权证据缺失，均为 `NO-GO`，不得进入移动阶段。

## 阶段 2：单段低速移动

只有在阶段 1 通过、获得书面授权、现场安全监护到位后，才启动单独的标准模式 Adapter。

第一段建议使用当前车辆所在站点到直接相邻站点，例如：

```text
LM1 → LM2
```

约束：

- 每段使用新的唯一 permit/task ID；
- 最大速度保持 `0.3 m/s`；
- 先申请控制权，再重新读取完整预检；
- 预检通过后只派发一次；
- 轮询 `accepted/moving/arrived/failed/unknown`；
- 必须读取并确认到站状态后，才允许下一段；
- 超时或未确认结果不得自动重试；
- 任何急停、阻塞、定位异常或人工接管立即停止本段并记录。

## 阶段 3：完整往返

由于控制器地图是有向图，不能假设存在反向直达边。应按控制器权威地图逐段执行，例如：

```text
LM1 → LM2
LM2 → LM3
LM3 → LM1
```

每段都要完成：

```text
到站确认 → 新建/授权下一段 → 获取控制权 → 预检 → 派发一次
```

不能将多段路线拼成一个未经批准的任务，也不能用历史 `LM3` 状态替代当前到站确认。

## 阶段 4：结束与异常恢复

正常结束：

- [ ] 车辆到达目标站；
- [ ] 任务状态为 `completed/arrived`；
- [ ] 控制权释放成功；
- [ ] 车辆保持安全静止；
- [ ] Adapter 停止，端口释放；
- [ ] 保存状态、任务、控制权和审计日志。

异常结束：

- [ ] 记录异常发生时的车辆位置、速度、定位置信度和控制权；
- [ ] 不自动重试移动/取消；
- [ ] 由现场人员执行人工接管或急停；
- [ ] 任务标记为 `unknown` 或 `manual_intervention_required`；
- [ ] 重新只读预检后再决定是否恢复；
- [ ] 不复用原 permit/task ID。

## 通过标准

单 AGV 本轮只有同时满足以下条件才算完成：

1. 至少一段去程和一段返回路线在 `0.3 m/s` 限速下完成；
2. 每段均有控制权、派发、移动、到站和释放证据；
3. 无未确认任务、未确认取消或未知控制权残留；
4. 当前地图、站点和有向边均来自控制器权威读取；
5. 异常/人工接管路径有记录；
6. 总控电脑是唯一控制客户端；
7. 本轮不涉及机械臂、视觉或仪器写入。
