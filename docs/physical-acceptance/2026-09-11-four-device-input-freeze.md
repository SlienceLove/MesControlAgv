# 四类设备物理验收输入冻结（2026-09-11）

本文件冻结两周 P0 单样本验收所需的设备身份、协议边界和现场输入。它是验收输入清单，不是授权书；没有现场签字、最新只读预检和安全负责人批准，不得切换到真实写入模式。

## 固定设备身份

| 类别 | 系统 ID | 当前协议/状态 | 必须由现场补齐的输入 |
| --- | --- | --- | --- |
| AGV | `AGV-01` | `vendor-tcp`；默认 `read-only-preflight` | 控制器真实主机、最新 map/version/MD5、站点和有向边、设备 epoch、操作员与安全监护人授权 |
| AUBO 机械臂 | `ARM-01` | WebSocket JSON-RPC `192.168.1.102:9012`；受控开关默认关闭 | 控制器地址确认、设备 epoch、批准的程序目录和白名单、现场启停授权 |
| 开盖分液 | `SAMPLE-WORKSTATION-01` | HTTP `/Service/`；端口以现场确认值为准（文档出现 `8082`/`8808` 两种值） | `EquipmentNo`、真实 BaseUrl/端口、认证/防火墙要求、厂家版本及各 POST 返回样例 |
| 离子色谱 1 | `CIC-D160-01` | D160+ 只读观测；`protocol_pending` | 厂家模块、正式 `equipmentCode/strCode`、序列号、连接会话、Config/Command/停止语义、结果文件关联 |
| 离子色谱 2 | `CIC-D160-02` | D160+ 只读观测；`protocol_pending` | 同上，必须单独提供，不得复用 01 的身份或任务号 |

AGV 的 `deviceParameters` 和 AUBO 地址可以保留非敏感占位值；真实主机、串口、令牌和抓包只通过受控部署环境变量或现场密封证据注入，禁止提交到仓库。

## 门禁与并行泳道

- 默认配置必须保持 `Adapter:RunMode=read-only-preflight`、AGV `AcquireControl=false`、`EnablePush=false`、自动派发关闭；启动配置不授予移动权限。
- 工作站 `EquipmentNo` 为空时只能启动只读模块；`ControlEnabled=true` 在正式受控驱动交付前必须被拒绝。
- 离子色谱两台设备均明确 `controlEnabled=false` 和 `protocol_pending`。厂家模块未交付时只提供身份/状态查询，禁止猜测或发送 `Config`、`Command`、进样、停止、复位报文；其泳道阻塞只影响离子色谱节点，不得阻塞 AGV、AUBO、工作站和报表链路。
- 每台设备使用独立的配置、连接、任务、epoch、操作和结果关联。`CIC-D160-01` 与 `CIC-D160-02` 不得以 fallback 编号互相替代。
- 任何写入前必须有新的只读预检、唯一 `OperationId`/幂等键、现场操作员和安全监护人确认。超时、断线、响应不完整或任务号无法关联时进入 `Unknown`，只允许查询和人工收口。

## 输入收集顺序

1. 现场签字确认设备 ID、控制器/网关地址、端口、序列号和设备 epoch。
2. 对 AGV、AUBO、工作站分别保存只读健康/身份响应摘要；不保存令牌、完整样品数据或未脱敏抓包。
3. 对离子色谱记录厂家模块交付状态。未交付时登记 `protocol_pending`，继续执行其他设备的离线和真实单次验收准备。
4. 将补齐后的值注入隔离部署配置并重启服务；不得在运行中的 WPF 页面动态切换物理模式。

## 当前结论

输入冻结完成，但整体仍为 **NO-GO**：AGV/AUBO/工作站需要新的现场授权和预检；两台离子色谱在厂家模块到位前不能宣称真实写入完成。后续实现应沿独立泳道推进，不因 `protocol_pending` 停止其他设备流程。
