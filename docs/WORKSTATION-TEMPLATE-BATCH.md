# 开盖分液：单任务模板与 Excel 批量导入

开发分支：`feature/workstation-template-batch`，由 develop 建立并同步已确认的 UI 导航提交。此任务涉及 WPF、Excel 契约及 MES 网关；未修改设备启动流程。

## 操作入口

设备状态查询 → 开盖分液 → 顶部“单任务模板”或“批量导入任务”。离子色谱页不显示这两个按钮。

1. 单任务模板：可在弹窗内加载并选择设备已有任务（任务编号＋名称），只读复制其全部分液参数；也可输入已知任务编号，或打开本地 XLSX 模板。复制模板会生成新的 20 位任务编号，不覆盖来源任务。
2. 修改任务名称和分液明细，保存本地模板 / Excel 样表。模板文件就是可重复使用的本地 XLSX，不需要额外维护服务器模板库。
3. 使用 Excel 复制行：同一任务编号可有多行，每行一条分液明细；相同编号的任务名称必须一致。不同任务用不同编号。
4. 在批量页选择 XLSX，校验通过后显示任务数量、各任务明细条数及选中任务的完整明细。
5. 复核后填写操作人，点击“确认导入（不启动）”。服务器拆分为单任务厂家 XLSX，逐项导入并精确回读；不会初始化、更新样品条码或启动任务。运行仍需既有独立准入流程。

## Excel 规则

唯一工作表名：`批量任务`。表头、顺序固定：

任务编号、任务名称、溶剂参数编码、枪头位模块参数编码、枪头行X、枪头行Y、来源孔板模块参数编码、来源孔板行X、来源孔板列Y、目标板模块参数编码、目标孔板行X、目标孔板列Y、移液量(µL)。

- 编号为文本，1–20 位 ASCII 字母、数字、下划线或短横线，不允许会造成上传文件名冲突的保留名。导出模板将所有单元格保存为文本，避免 Excel 损坏长编号。
- 模块、溶剂编码使用现场实际厂家配置；不推断设备编码。
- 来源/目标 X、Y 和体积是正整数。枪头 X/Y 须均为正整数，或同时为 0 以沿用厂家默认枪头设置。
- 每批 1–100 个任务、最多 5000 条明细、4 MiB 压缩体积；不接受公式、外链工作表、重复单元格、异名同编号、额外数据列。支持 Excel 的共享字符串。
- 此表是中控操作样表，不直接上传到厂家。中控转换为已验证的“两工作表、单任务”厂家格式，不改变厂家协议。

## MES 与重放边界

新增 POST `/api/workstations/{deviceId}/task-batches/import`，JSON 为 `WorkstationBatchRequest(RequestId, Actor, Tasks)`，返回每项状态与批次摘要。

导入前检查控制能力、导入能力、在线空闲以及现有任务编号，重复编号禁止覆盖。分页按实际返回数量推进，不能把短页误认为查询结束。每项导入前再次检查空闲状态。

同一请求号、相同内容返回已保存结果；同号不同内容拒绝。开始写入前记录 Importing 意图，结果不确定时记 Unknown 并停止后续任务。该设备存在 Importing/Unknown 记录时拒绝新批次，不自动重试、自动删除或重建任务。查询结果里 Pending 表示尚未执行。

服务器日志默认位于稳定 contentRoot 的 `data/workstation-batches`；可通过 `WorkstationBatch:JournalDirectory` 指定持久目录。升级须保留该目录，禁止为了重试而删除不确定记录。文件锁防止使用同一日志目录的多个 MES 进程同时写入。不同 contentRoot 的 MES 不应同时拥有同一工作站的导入控制权。

客户端先将请求编号、设备和内容保存到 `%LOCALAPPDATA%/MesControlAgv/workstation-batches`，收到结果后补充回执，也可导出文本结果。导入专用超时为 30 分钟，普通读写超时不变。中断或结果不确定时按请求编号人工核对；本版本不提供强制重置入口。

## 部署范围

本地模板编辑、Excel 导出和预览只需新版 WPF。真正批量导入需要新版 MES 同时提供上述接口，并使用能在 capabilities 返回 `TemplateVolumeUnit` 的新版 Adapter（2026-09-24 集成补齐）。旧现场 MES 返回 404 时，UI 明确提示尚未部署，不绕过 MES 直连设备。

MES 从网关能力获取并固定本批厂家文件单位，按此生成单任务 XLSX、传递 `fileVolumeUnit` 并核对回读单位。中控 DTO 与操作员批量样表继续使用 µL；例如 50 µL 在 Milliliters 厂家文件中为 0.05。旧 Adapter 不声明单位或声明非法值时，导入前拒绝，不猜测单位。批次日志新增 `FileVolumeUnit`；历史缺字段记录仍可读取，同请求重放只返回原记录、不重新发送。

开发验证均使用离线替身、临时文件或 TestServer；未上传真实任务、未重启现场服务。新服务部署及真实导入须作为后续现场操作单独安排。
