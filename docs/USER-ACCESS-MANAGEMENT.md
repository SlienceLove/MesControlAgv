# 本地登录与用户权限首版

已确认：本地账号、管理员/操作员/只读三种固定角色，蓝白 WPF 登录页、用户管理、修改密码和退出登录。客户演示使用独立端口、模拟设备及数据库，不接管现场进程。

实现计划：账号与会话契约 → SQLite 账号库和服务端访问控制 → 登录/用户管理窗口 → 主界面身份和权限 → 隔离演示启动器 → 回归与权限绕过检查。

认证由 MES 校验。密码使用 ASP.NET Core PasswordHasher（PBKDF2），仅保存哈希；随机会话令牌仅客户端内存保存，服务器仅存令牌 SHA256。会话八小时有效；登出、改密、停用和角色变更使有关会话失效。连续五次密码错误锁定五分钟；初始化管理员密码通过进程环境传入，不提交固定口令。不能停用或降级最后一个管理员。

权限：所有 MES 业务接口要求会话；只读账号只能 GET/HEAD；操作员可操作任务、实验及物料，不能管理用户、系统配置或直接设备调试。未知写入接口默认仅管理员。权限不替代现有物理准入。业务 JSON 操作人由服务端登录身份覆盖，不采信客户端自行填写的 actor/operatorName。

演示通过 `Access:Enabled=true` 显式启用；现有未迁移现场实例不改变行为，不声称它们已经受到认证保护。独立账号数据库与业务数据库分开。管理员角色只授权 MES，不开放 Adapter/厂家直连接口；正式联网部署需由网络隔离和服务身份另行保护网关，使用 HTTPS，不以本地 HTTP 演示作为生产安全验收。

界面预期：登录后 KPI；右上角账号、角色、改密和退出；管理员可打开用户管理（账号、姓名、角色、状态、最近登录）。退出登录只撤销会话和关闭业务界面，不停止后台服务或任务。角色决定导航/操作控件，同时服务端拒绝越权调用。

验证：错误密码、账户锁定、无令牌401、只读写入403、操作员配置403、管理员用户管理、最后管理员保护、会话撤销、身份不可伪造、旧配置回归、WPF 登录窗口布局及隔离演示。第一版不做 SSO、组织架构、自定义权限树、网络部署或真实设备动作。

## 当前版本结果

已完成本地演示链路：`AccessStore` 独立 SQLite 账号库、PBKDF2 密码哈希、8 小时会话、失败锁定、会话撤销、管理员最后账号保护；MES 中间件统一执行 401/403，登录身份覆盖业务请求中的 actor/operatorName，旧的物理准入逻辑仍保留。

WPF 已接入登录窗口、当前用户/角色显示、退出登录和管理员“用户管理”窗口。管理员可查看、创建、启停账号和重置密码；操作员及只读用户不显示入口。客户演示包和启动器在 `artifacts/user-access-demo/`，启动器通过环境变量显式启用登录并注入本地演示账号：`admin / DemoAdmin2026`、`operator / DemoUser2026`、`viewer / DemoUser2026`。公共 FieldSimulation 配置不启用登录、不保存口令；只有显式启用且首次初始化账号库时，缺少合规初始化口令才拒绝启动。生产配置必须通过安全配置覆盖，不能直接使用演示口令。

串行回归：MES 585 项、WPF 623 项全部通过；Release 演示发布成功。已手工确认登录页、管理员角色显示、用户管理窗口、`/api/access/users` 读取和只读账号写入 403。服务端会覆盖 actor、operatorName、operatorAccount、requestedBy、createdBy、updatedBy、submittedBy、approvedBy、authorizedBy、completedBy 等身份字段，避免客户端污染审计或物理授权。模式接口网络异常不会再静默跳过登录。未启用现场 PhysicalAcceptance 登录，也未改变开盖分液会话或现场服务。

## 下一阶段完成项

已补齐账号日常闭环：管理员可以编辑姓名/角色、启停账号和重置密码；所有用户可在右上角修改自己的密码；修改密码、停用账号或角色变更会结束相关会话；退出登录会返回登录窗口，不停止 MES、Adapter 或模拟任务。用户管理表格为只读展示，操作通过明确弹窗完成，避免误编辑。

主窗口每 30 秒只读校验当前会话；服务端会话过期、账号停用或网络恢复后发现 401 时，业务窗口会回到登录页，不会停止后台服务。修改本人密码或管理员修改自身资料也复用同一重登录流程。

只读用户进入主界面后，侧边栏会禁用业务写入相关页面；可查看 KPI、排程、物料、设备状态、数字孪生和运行记录。页面内未列入只读白名单的按钮禁用，表格设为只读，并保留鼠标/键盘拦截；右上角个人改密和退出登录不受业务只读限制。MES 服务端仍是最终权限判断，按钮名称白名单不是安全边界。会话监测在网络暂时不可用时继续重试，不会误判为退出。

新增 AccessClient 会话/错误处理测试 2 项；全量 MES/WPF 回归继续使用串行模式，避免并行 MSBuild 内存峰值。演示包仍从 `artifacts/user-access-demo/Start-Demo.ps1` 启动，Adapter 使用隔离端口 5941。
