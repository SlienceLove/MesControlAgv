# 离子色谱导入入口合并

用户明确要求取消独立“仪器任务导入”页面，将任务导入直接放在设备通讯状态的离子色谱页按钮中；已确认弹窗导入、预检、下发方案。

## 范围与实施

- UI 分支、主目录独占，基线 develop 6a5e7d1；不修改 MES、厂家协议或现场服务配置。
- 设备状态查询 → 离子色谱 → “导入样品任务”打开有主窗口归属的模态弹窗，复用现有控制视图和同一视图模型。保留 CSV/XLSX 解析、预检、独立下发确认、结果与复核建议；不自动启动。
- 弹窗关闭保留导入草稿及已准备身份，重开不新建模型或重复下发；操作忙碌时阻止关闭，避免未完成请求的应答被误认为取消。返回状态页仅重新 GET 记录与状态。
- 删除独立导航、对应 Tab 和过时的组合页面包装（包括已失实的“开盖分液接口预留”占位）；同时去掉隐藏的重复离子控制 Tab，组件仍供弹窗复用。开盖分液真正的单任务模板/批量入口保留。
- 原 WPF_START_PAGE=ShineLabControl 启动值兼容重定向到设备状态查询，不自动弹出或下发。
- 验证顺序：导航/窗口复用和关闭行为 → 大小窗口及真实按钮弹窗 → WPF 全量 → 只读审查 → develop 集成。MES、Adapter、运行中的 WPF 暂不重启。
