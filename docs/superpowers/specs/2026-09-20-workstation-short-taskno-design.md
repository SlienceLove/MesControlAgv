# 厂家任务号最小长度兼容

用户已确认：后续新任务号缩短至20字符内，先完成离线修正和复现材料，不重新导入或启动真机。依据和不确定性见任务号兼容排查；旧schema限制20，不代表已确认现场schema。

## 已确认设计

- 仅修改正式准备的新号生成：WS + 9个密码学随机字节的大写十六进制，共20个ASCII字符、72位随机空间。不使用时间截断，不使用区分大小写的编码；时间继续保存在PreparedAt。
- 中控Job/Preparation GUID、溯源绑定和持久化结构不变；不新增编号管理组件或数据库迁移。
- 同请求幂等重放保持原号；旧42位编号可照常读取，Unknown记录不改、不重新上传或准入。
- 模板来源、目标、枪头默认值、体积和精确回读规则不变。现场服务不升级、不重启。
- 离线核对固定时钟下多次准备的长度/字符集/区分度、幂等返回和完整准备→导入替身→带码启动替身→完成链；历史长号Unknown继续可读取且拒绝写入。
- 从已冻结的现场准备JSON用原生成器还原上传XLSX，必须匹配当时SHA256。准备给厂家的复现材料只做本地文件输出，不包含自动上传/启动脚本；旧原件与任何新号示例明确区分。

编号随机性使重复概率很低，并非数学意义绝对唯一；保留既有记录约束，不增加跨设备编号服务。缩短编号只消除历史字段兼容风险，不宣称现场入库问题已解决。
