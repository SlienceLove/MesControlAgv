# 工作站任务准备编辑提效（A）

用户已确认方案A：统一设置每孔体积，实时汇总来源/目标孔/各来源计划用量/总计划用量，明确未保存修改；不做方案B的检索导出，不新增设备调用、弹窗或枪头管理。

## 最小实现

- 沿用现有ExperimentWorkstationPreparationViewModel和准备面板；新增体积文本输入（默认50µL）及显式“应用到全部行”按钮。输入本身不改任务；点击后只改当前Transfers的VolumeMicroliters，来源、目标、枪头和顺序原样保留。
- 只接受int范围内正整数；无效输入给出行内提示，不使用上一个有效输入。没有表格、只读/忙碌或Importing/Unknown时不可批量应用；执行函数再次核对可用状态。
- 来源按模块+X/Y分组；目标孔按目标模块+X/Y去重；另显示分液条目数，避免重复目标被误解成多个孔。总量/分组量用long累计，若有非正体积则显示待修正，不显示可被误解为有效用量的合计。
- 汇总写明“计划”，不宣称实际已分液。来源身份复用当前转移行SourceIdentity，历史快照仍显示冻结身份而非当前样品名称。
- 表格/绑定变化、载入/保存及切换任务时更新汇总；切换清空旧值。批量修改沿用MarkDirty，未保存时继续阻止导入；相同体积的无变化操作不产生新脏状态。
- 新控件放在现有可滚动准备区域，采用换行布局，不增加固定大面板遮挡节点时间线；状态标注区分尚未保存与有未保存修改。

## 验证及边界

以两来源16孔测试1000→50，预期来源各400、总800；覆盖输入错误、逐行更新、溢出累计、重复目标、任务切换、忙碌/异常状态、保存后恢复导入资格和XAML绑定/布局。只用替身MES，保持原保存/显式导入/运行准入接口不变。不打开现场WPF、不重启服务、不导入或启动、不合并日常分支。
