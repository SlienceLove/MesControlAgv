# 联调阶段等待判定简化方案

状态：2026-09-14 09:14 用户批准的最小联调方案已实施并通过针对性离线回归，等待现场单次验证。

## 目标与边界

用户要求优先跑通 WPF 单次真实流程，简化判定并注释掉不必要的重复检查。
当前继续离线，不启动现场服务、不连接 AGV/AUBO，不执行旧 Unknown run。
本次不重写状态机、不引入多套运行模式、不增加无人值守或批量恢复功能。

## 已确认的问题

- 上次 AGV 两次到站 Unknown 分别涉及：观察已有任务时复用新派发 Ready 门禁；
  到站后的五秒 Stabilizing 被视为异常。这两处及到站回执/状态轮询先后竞争已离线修复。
- AUBO 的正常 Running/Stopped 在现有 probe 中均被允许；不能把 AGV 的旧问题直接推断到机械臂。
- 工作站任务状态/详情读取一次临时异常会直接 Unknown；完成后额外查询设备编号失败
  也会覆盖已取得的完成证据；工作站忙态被当作非暂态 blocker 导致 readiness epoch 变化。
  这些审查确证的问题已在本轮修复；厂商模块仍未到位，不是上次 AGV 现场失败原因。

## 两个可选范围

1. 最小联调简化（推荐）：分开启动准入与运行观察，去除后者重复的整套 Ready、
   地图和授权门禁，使用已绑定任务回执处理等待/完成，并修复工作站只读轮询问题。
2. 最小代码差异：暂时只简化 AGV 的运行观察，其余节点保留原逻辑；改动更少，
   但已知工作站问题仍需后续修复。

不建议全局关闭所有校验或现在重构整个工作流框架。

## 推荐判定规则

| 阶段 | 简化后职责 |
| --- | --- |
| 启动与下发新动作前 | 保留必要的连接、控制权、配置/程序及设备硬状态检查。沿用一次确认的单次运行授权，不增加人工确认步骤。 |
| 已确认派发后的普通观察 | 跟踪当前绑定的 task/operation；Waiting、Accepted、Running 或正常到站过渡继续等待。观察路径不每轮重复运行整套启动准入。 |
| 完成 | 使用匹配的到站/程序完成回执；同一节点只完成一次、同一动作只发送一次。设备编号等展示信息不能推翻完成证据。 |
| 短暂读取失败 | 只重试查询，使用已有的轮询间隔和合理的有界观察窗口，不重新发送控制命令。窗口用尽明确记录“结果未确认”，不伪造成功。 |
| 必须保留的边界 | 急停/保护停、错误任务回执、明确失败，以及命令是否执行不明时禁止自动重发。MES 进程重启与历史 Unknown 不自动恢复执行。 |

“移除运行观察中的重复授权检查”不等于自动重新授权、不等于重放历史动作，
也不等于关闭 Adapter 对真正设备写操作的必要条件。
不直接把所有 Unknown 改成成功或无限等待，不把厂商尚缺失的动作模拟成真实成功。

## 实施与验证范围

实施清单：① AGV/AUBO 普通观察移除启动门禁，启动和真正的新动作保留原检查；
② 工作站只读重试、非阻断完成信息、正常忙态不改变授权版本；
③ 更新等待语义回归、只读复核、构建并记录离线交接。
现有 writing-plans 技能不可用，按此短清单执行，不新增规划流程或反复请求批准。

- 优先调整 WorkflowFieldNavigationWorker 的当前实例观察路径，严格区分 RecoverAsync。
- AUBO 保留已修复的连续 Stopped 计时及禁止重发；删除重复判定前先补正常运行/过渡用例。
- 工作站补 Waiting/Running 连续轮询、临时读失败恢复、完成详情延迟、附加元数据失败用例。
  不把 Paused 自动等同正常完成，也不自动 Resume。
- 修改前用内存网关复现目标失败，修改后检查完整四段导航/三次回原点的软件链路。
- 保留任务错配、明确失败、进程重启和命令回执不确定的反例，确保不会重复下发。
- 只运行内存、临时测试库、loopback 测试。确认软件删减完成后再请求现场连接与监护。

## 实施结果与证据

- AGV 当前实例运行观察不再重复地图、整套 Ready、epoch/再次授权门禁。
  匹配的持久化 Arrived 可直接完成中间 Move，Stabilizing 或残留的临时 Blocked 不再阻塞该完成记录。
  下一设备动作仍有启动检查；最后一段释放控制权是新写操作，等待原准入，不因等待而直接 Unknown。
- AUBO 完成观察使用指定设备的程序回执，保留设备编号核对、程序匹配、连续 Stopped
  窗口和急停/保护停等硬状态判断；读失败重置连续完成计时，只重试读取，不重发 load/run。
- 工作站任务与详情读取临时异常、空/坏 JSON 在原完成时限内重试；任务/操作身份错配
  和明确 Unknown 仍拦截。完成后不再追加可能推翻成功结果的设备编号读取。
  正常 Running/Initializing/Paused 只阻止新派发，不再改变已授权设备版本。
- WPF Running 监控只显示当前节点回执等待，不再重复 AGV 全预检、机械臂准入读取
  或许可到期告警；Prepared 的启动预检、Unknown 人工核对提示与终态清理核对保留。
- 不修改厂商模块启用状态、不引入模拟真实成功、不重启/恢复历史 Unknown run。
