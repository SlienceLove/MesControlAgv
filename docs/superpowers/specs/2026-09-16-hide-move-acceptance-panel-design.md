# 流程运行监控隐藏现场 Move 验收许可面板设计

## 目标

在 WPF“流程运行监控”页面中完全隐藏“现场 Move 验收许可”面板，释放垂直空间，使下方只读运行画布以及“节点执行 / 设备操作 / 时间线”更容易查看。

## 范围

- 仅修改 `WorkflowRunMonitorView.xaml` 的界面呈现。
- 面板不再参与布局，也不保留折叠占位。
- 保留现有 ViewModel、命令、MES 接口和现场 Move 验收能力，便于后续重新启用。
- 不改变工作流运行、开盖分液 worker、权限校验或设备控制行为。

## 实现设计

将“现场 Move 验收许可”对应的根 `Border` 设置为始终折叠。使用 WPF 的 `Visibility="Collapsed"`，让控件既不可见也不占用布局高度。面板内部现有绑定和命令保持不变，避免为一次显示策略调整引入无关重构。

运行监控页面其余区域继续使用现有 Grid/StackPanel 布局；面板折叠后，只读运行画布和底部明细标签页自然上移。

## 数据流与错误处理

本次修改不改变数据流。现场 Move 验收状态仍可由后台服务和现有 API 维护，只是不在此页面展示。由于没有新增输入、命令或网络调用，因此不新增错误分支。

## 验证

- WPF 视图绑定测试确认运行监控视图仍能加载。
- 相关 WPF 测试通过。
- 构建 WPF 项目，确认 XAML 编译通过。
- 启动界面后确认“现场 Move 验收许可”完全不可见且不占位，下方画布和标签页上移。

## 非目标

- 不删除现场 Move 验收功能。
- 不新增“显示高级面板”开关。
- 不调整流程画布高度、窗口尺寸或其他监控面板。
