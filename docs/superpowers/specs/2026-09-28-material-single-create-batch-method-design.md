# 物料单条创建与批次检测方法关联

日期：2026-09-28
分支：`feature/sample-detection-standards`
状态：待用户复核

## 选择与范围

现有物料模块的样品只提供 CSV/XLSX 导入；耗材已有字段有限的“快速入库”，但缺少可录完整信息的单条建档。新增“新建样品”和“新增耗材”入口，不改变既有导入、快速入库、样品流转或设备任务链路。

检测方法与整个物料样品批次关联：同一 `SampleBatchId` 只绑定一个方法编号，批次内所有样品继承它。参考网页也以批次选择一个标准。备选的“每个样品独立方法字段”改动更少，但不能保证批次一致；“样品与方法多对多”更灵活，却超出当前单条建档需要。因此首版采用批次绑定。方法编号是用户维护的检测标准编号，不是 ShineLab 设备下发的 `DetectionMethod` 参数。

## 界面与操作

“物料与库存”的样品页增加“新建样品”按钮。表单填写样品条码、样品批次、样品类型、物料编码（可空）、库位，并从当前启用的检测标准中选择一个方法。表格增加“检测方法”列。已有批次若已绑定方法，表单显示并沿用该方法；选择不同方法时提交前明确报冲突。保存成功后刷新样品列表并显示新记录。

耗材库存页增加“新增耗材”按钮，表单包含物料编码、名称、批号、数量、单位、库位、条码、规格及可选生产/失效日期。原“快速入库”保留用于少量字段的补货；新增表单处理完整单条记录。两种表单都使用现有物料导入的单行预览与提交接口，不引入并行的创建业务链路。

“检测判定”弹窗打开已绑定方法的样品时，默认选中该方法的当前启用修订；批次已绑定方法时不能改选其他方法。若方法已停用，显示原因并阻止新判定。未绑定方法的历史样品维持手工选方法的兼容行为。

## 数据与服务

MES 新增 `SampleBatchDetectionMethods` 表，按规范化的批次编号唯一保存方法编号、操作人和创建时间。该表不固定标准修订：方法修订升级后，新判定使用当时启用版；每条已保存的判定继续保留其原修订、规则和检测值快照。批次绑定不随标准停用而删除。

物料样品响应增加可空的检测方法编号，按样品的批次关联读取。`SampleImportRow` 增加可空方法编号；单条新建必须选择，旧 CSV/XLSX 文件继续可不提供。导入时同一请求内同批次的显式编号必须一致，与已绑定批次冲突则拒绝；编号存在且启用后才允许建立新绑定。没有显式编号的旧导入行自动继承已有批次绑定，尚未绑定的旧批次保持无方法状态。样品条码、库位、耗材效期和重复请求仍使用现有预览/提交校验及幂等机制。

耗材单条创建转成一行 `ConsumableImportRow`；不改变耗材库存表或快速入库端点。物料台账样品与历史“样品流转”记录仍保持原有两个来源，不强制合并。

## 验证

MES 测试覆盖：新批次绑定、同批次继承、显式冲突、同次导入冲突、方法不存在/停用、旧文件无方法、标准升版后批次和历史判定不变、已有数据库增表。WPF 测试覆盖：两个单条表单的字段与预览/提交、批次方法默认选择、判定弹窗锁定方法和导航不回退。离线回归不得触发真实设备控制。
