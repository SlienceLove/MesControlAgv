## 最小文件/通讯实现

1. 定义一份单任务模板模型：任务号/名称和有序分液行。来源/目标模块编码与坐标原样保存，尚不猜测1/2号大瓶对应哪个模块，也不把模块编码当样品ID。
2. 用标准ZIP/XML读取与生成实测xlsx结构，不依赖Excel进程；保持两个工作表固定顺序、列顺序、文本编号和正整数坐标/体积。拒绝多任务、错误表头、公式或缺行等不能确定解释的模板。
3. 新增强类型模板下载方法：解码真实xlsx，检查内部TaskNo与请求相符，保留文件SHA256。
4. 实现既有ISampleWorkstationTaskImporter：验证单任务xlsx；短且无路径的xlsx文件名；编码已确认的原始报文；发送一次ImportExperimentalTask；仅200/导入成功后读取同任务模板，逐行比较任务身份及所有分液参数；相符才返回导入成功。所有失败不自动重试，不调用启动/条码更新/初始化。
5. Adapter暴露专用模板下载及POST文件导入路由（application/octet-stream + fileName query），遵守控制开关。MES先提供相同的强类型客户端接口；暂不开放绕过样品核对门禁的MES通用写路由。
6. 中控业务层后续须将显式大瓶位置绑定与Verified快照合并，持久化来源ID/目标位置及导入记录，再挂接WPF与正式worker；本次不宣称完成UI/真实导入/全链路溯源。
