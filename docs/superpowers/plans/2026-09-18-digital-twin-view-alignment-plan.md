# 视角摆正实施清单

依据已获用户批准的同日 view-alignment-design；writing-plans 技能未提供，使用本地清单。只在既有隔离工作区工作，不提交、不合并、不控制 AGV。

1. 跑 WPF/JS 基线，核对模型几何轴；相机功能独立成模块，统一正交/透视的投影构图。
2. viewer 使用相机模块；常用工具栏提供唯一 top 入口；窗口 resize、首次位姿、聚焦与地面切换保留当前方向，显式全景按钮恢复摆正视角。
3. 运行范围覆盖站点及规划曲线；保留原始模型、地图变换、位姿守卫与控制边界。
4. 添加相机构图单测，扩展原生离线冒烟验证 top 下位姿、resize、选取与标定；截图检查全景/俯视并核对车头证据。
5. 只读独立审查，处理必要反馈。构建新独立预览包；仅替换任务自己的只读预览窗口，不影响服务，交付截图及测试结果。
