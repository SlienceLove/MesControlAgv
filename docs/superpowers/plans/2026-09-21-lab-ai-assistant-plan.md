本机没有 writing-plans 技能，按用户已确认设计使用以下替代清单。范围：Excel 优先的实验报表助手、小模型接入、独立 i5／8 GB 主机部署准备；不动现场设备控制。

- [x] 建立独立分支／worktree，Domain 基线 48 项通过，确认用户设计与 Excel 补充。
- [x] 独立 Reporting 库：快照、任务统计、测量预览和验证、来源及不可变报告。
- [x] Excel 模板与多工作表导出、CSV／HTML 兼容，编号／公式／压缩包边界测试。
- [x] MES 有界只读报表查询、本地 Ollama 单并发摘要、取消／离线退化测试；120 秒超时配置，真实超时与资源释放现场验证。
- [x] WPF 报表助手入口、导入确认、统计／AI 分离、导出与取消；独立请求不进入设备轮询链路。
- [x] 8 GB CPU 配置、独立电脑安装及连接说明、10 组样例和性能测量工具。
- [x] Reporting31／MES585／WPF625 测试通过（WPF 排除两项 linked-worktree 越界演练测试）；原生 UI 冒烟通过；只读复核无阻断；独立包准备完成。
- [ ] 获得目标电脑访问方式后部署，测冷启动／生成耗时／峰值与空闲内存，检查摘要事实；报告是否建议加内存，不用离线测试代替实测。
