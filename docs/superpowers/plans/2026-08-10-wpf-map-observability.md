# WPF 地图可观测性与操作效率计划

> 状态：已完成（2026-08-10）

## 目标

在上一阶段真实 `.smap` 几何、路线聚焦、缩放/平移和身份校验的基础上，补齐地图的只读观测能力：可选栅格背景、可控图层、站点详情和可回归验证。默认仍然不连接或控制实体 AGV；地图身份校验失败时，运行态 AGV 与活动路径叠加必须保持关闭。

## 范围与验收标准

1. `normalPosList` 以单一高效视觉数据（优先 `WriteableBitmap` 或等价模型）提供，默认关闭，开启后不创建数万个独立 WPF 元素。
2. 图层状态至少覆盖墙线、路线、站点标签、AGV/活动路径和栅格背景；状态可观察、可测试，且身份校验失败不能重新开启 AGV/活动路径。
3. 点击站点显示只读详情：`.smap` 标记、MES 映射 ID/名称、坐标、启用状态、关联路线；不增加派发、控制或编辑动作。
4. WPF 与 Domain 测试、Release 构建和本地截图验证通过；更新 README、进度、设计文档和本计划的完成状态。
5. 只提交本阶段及上一阶段地图实现所需文件，创建并推送独立分支 `feat/wpf-map-observability`。

## 并发任务

### A. 栅格背景数据模型

- 从 `MapLayout.ScanPoints` 生成稳定的像素/点集合或位图输入。
- 默认关闭，切换只影响栅格层，不影响墙线、路线或站点。
- 补充边界、空数据、采样规模和性能安全测试。

### B. 图层状态模型

- 提供墙线、路线、站点标签、运行叠加、栅格背景的可观察状态。
- 运行叠加状态由地图身份校验结果约束，失败时强制关闭。
- 补充默认状态、切换和 fail-closed 测试。

### C. 站点选择与详情模型

- 以 `.smap` 站点为主键，保留 MES 映射与关联路线信息。
- 支持选择/清除选择和只读详情字符串或记录。
- 补充未知站点、映射站点、关联路线和清除选择测试。

### 主线集成与验证

- 接入 `MapViewModel`、`ReadinessViewModel`、`MainWindow.xaml(.cs)`，保持现有自动布局回退和身份校验门禁。
- 增加图层工具栏、站点点击处理、详情面板和栅格视觉绑定。
- 运行全量测试、`Release` 构建、`git diff --check`，记录截图和结果。
- 精确暂存、提交并推送 `feat/wpf-map-observability`。

## 完成记录

- `MapRasterLayerViewModel` 把扫描点量化为单一、上限为 `2048x2048` 的 Gray8 像素缓冲；默认隐藏，并对输入点数量做确定性采样。
- `MapLayerStateViewModel` 管理墙线、路线、站点标签、运行叠加和栅格图层。身份校验不一致时，运行叠加门禁会强制关闭并禁用其控件。
- `MapStationSelectionViewModel` 支持按 `.smap` 或 MES 映射 ID 选择站点；UI 使用完整站点命中区域和可访问按钮展示只读详情。
- UI Automation 在本地 Simulator 环境确认栅格开关、fail-closed 运行叠加和 `LM1` 详情；截图为 `artifacts/wpf-map-observability-final-20260810.png`。
- Release 构建为 0 警告、0 错误；全解决方案测试为 `312/312`。

## 明确不在本阶段

- 地图编辑、站点拖拽或写回 `.smap`。
- 地图图片/PDF 导出（保留为下一阶段候选，避免半完成）。
- 实体 AGV 连接、派发、运动或现场验收。
