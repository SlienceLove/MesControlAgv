AI轻量试用包（离子色谱电脑192.168.10.108，i5-13400 / DDR5 8GB）

本包只验证轻量模型效果及硬件负载，不安装中控、不连接仪器、不执行实验。
请在仪器空闲时运行，离子色谱软件保持原状；不要为测试关闭仪器控制服务。

首次运行
1. 完整解压到本机普通目录，例如 D:\LabAiPilot。不要在ZIP内直接运行。
2. 双击 1-Check.cmd。它只检查CPU/内存/系统/磁盘并生成host-check文件。
3. 如未安装Ollama，从官方 https://ollama.com/download/windows 安装。
   若公司不允许安装，可使用官方Windows便携包，放到本目录ollama子目录。
   本包不包含Ollama和约1.4GB的qwen3:1.7b模型，首次下载需联网。
4. 双击 2-Run-Test.cmd，输入Y确认仪器空闲。脚本检查模型服务并按需下载模型。
   首次下载时间不计入AI生成耗时。无需打开防火墙或配置SSH。
5. 等待测试结束，打开控制台提示的 results-日期编号 文件夹中的 report.html。
   将整个results文件夹和host-check JSON打包发回。报告可用浏览器打印成PDF供汇报。

怎么看结果
- 先看各用例生成的文字/方案是否合理，有无漏步骤或乱编。
- 再看耗时、最低空闲内存、模型进程工作集峰值和平均CPU占用。
- “结构符合”只表示模板顺序/补问结构符合预期，不等于业务理解正确。
- 全部样例为合成数据，模板是描述性演示目录，不是可执行现场流程。
- 内存紧张优先评估32GB；内存足但慢要评估推理算力；答错要评估模型能力和输入。
  不能从本次小模型测试直接得出必须64GB的结论。

边界
- 顺序运行1个数据摘要和5个流程规划用例，每次最多120秒，无自动重试。
- 默认CPU轻量模型qwen3:1.7b。规划复用中控代码：8K上下文、2048输出上限、4线程。
  数据摘要：2K上下文、384输出、4线程。两者均请求结束后卸载模型。
- 低于3GB空闲内存不开始；测试中低于约768MB时取消当前请求并停止后续用例。
  不杀任何仪器进程；取消后请等待模型服务释放内存。
- 如果本机已有模型正在使用，先完成那边工作；本包不会替其他会话卸载模型。
- 本包脚本不添加开机启动项，不改防火墙，不把无认证模型端口开放到局域网。
  若使用Ollama安装器，其自身可能添加托盘/登录启动设置；按公司要求管理。
- 自检报告标注“假输出”，不代表目标电脑性能。不要用自检报告申请硬件升级。
